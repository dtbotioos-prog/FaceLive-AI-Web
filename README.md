# FaceLive AI — версия с фото по умолчанию

Файл `default-face.jpg` — предоставленная пользователем фотография, которая автоматически загружается как источник наложения.

Загрузите все шесть файлов в корень репозитория GitHub Pages. Откройте сайт через HTTPS в Safari, нажмите «Запустить камеру». Понадобится интернет для загрузки MediaPipe и модели. При необходимости можно выбрать другую фотографию.

Это **геометрическое 2D-наложение**, а не реалистичный нейросетевой face swap. Качество и скорость зависят от устройства и браузера. Safari не может подменять видеопоток в TikTok/Instagram.

Используйте фотографии и видеозаписи с согласия изображённых людей.
